

## title
I opened a link I should not have

## subtitle
You opened a suspicious link, or typed your password into a site you did not know

## do-not
Do not wait to see whether anything happens. Change the password now, because whoever made the page may try it straight away.

## technical
- If you entered a password: change that account's password now, from a different device or browser.
- Turn on two-factor authentication on that account, so the password alone is not enough to get in. If you also typed a code on that page, sign out every other session after changing the password.
- If you use the same password anywhere else, change it on every account that shares it.
- If the link opened a file or an installer: disconnect from the internet. On Windows, run a Quick scan in the Windows Security app. On a Mac or a phone, install any waiting updates.
- Look in your inbox for "unusual sign-in" alerts from that account, which may already have arrived.
- Keep checking that account afterwards for new forwarding rules or auto-replies, sent mail you did not send, and changes to its recovery email or phone number.

## plain
- If you typed in a password on that page: change it now, on a different browser or device.
- Turn on two-factor authentication on that account, so the password alone is not enough to get in. If you also typed a code from your phone on that page, sign out of everything after changing the password.
- Did you use that password on other websites? Change it on those too.
- If the link made you download or open a file: disconnect from the wifi. On Windows, run a Quick scan in the Windows Security app. On a Mac or a phone, install any waiting updates.
- Check your inbox for "unusual sign-in" alert emails from that account.
- Keep an eye on that account afterwards for new forwarding rules, messages in Sent that you did not send, and changes to your recovery email or phone number.
