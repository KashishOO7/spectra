
## title
I opened a link I should not have

## subtitle
You opened a suspicious link, or typed your password into a site you did not know

## do-not
Do not wait to see whether anything happens. Change the password now, because whoever made the page may try it straight away.

## technical
- If you typed a password into the page, change it now on the real website or app it belongs to, opened yourself rather than through the link, from another device if you can, in case harmful software got onto this one.
- In the security settings of the account whose password you typed, turn on two-factor authentication and sign out every other session, because someone may already be signed in. You will then need the new password on your own devices.
- Give every other account where you used the same password its own new password.
- If you opened a file or an installer from the link, turn off wifi and mobile data, or unplug the network cable, while you check the device. On Windows, run a Quick scan in the Windows Security app, and on a phone, uninstall any app you installed from the link.
- Once the device is checked, connect it again and install any waiting updates.
- On an iPhone, if the page asked you to install a profile, search Settings for VPN & Device Management and remove it, which also removes the settings, apps and data that came with it.
- If the password you typed was for an email account, check that account over the next few weeks for new forwarding rules or auto-replies, sent mail you did not send, and changes to its recovery email or phone number.

## plain
- If you typed a password into the page, change it now on the real website or app it belongs to, opened yourself rather than through the link, from another device if you can, in case harmful software got onto this one.
- In the security settings of the account whose password you typed, turn on two-factor authentication and sign out of everything else, because someone may already be signed in. You will then need the new password on your own phone and computer.
- If you used the same password on other websites, give each of them its own new password.
- If you downloaded or opened a file from the link, turn off wifi and mobile data, or unplug the network cable, while you check the device. On Windows, run a Quick scan in the Windows Security app, and on a phone, remove any app you installed from the link.
- Once the device is checked, connect it again and install any waiting updates.
- On an iPhone, if the page asked you to install a profile, search Settings for VPN & Device Management and remove it, which also removes the settings, apps and data that came with it.
- If the password you typed was for your email, check that account over the next few weeks for forwarding rules or automatic replies you did not set up, messages in Sent that you did not send, and changes to its recovery email or phone number.
