# How to judge a tool before you trust it
Spectra does not tell you which app to install, because a company can be sold or change its terms after a recommendation is written, and the recommendation would not show it. These are the things to check instead, whichever tool you are looking at.

## Rows

### You can see the code
Open source
When the code is published, anyone can read it and check what the tool does. That does not prove the tool is safe, but it lets independent people look.

### Someone independent has checked it
Security audit · Third-party review
Look for an audit by an independent security firm, with its report published. A company saying it was audited, with no report to read, is not the same.

### It is still being worked on
Active development
Look at when it was last updated. A tool that no longer gets updates keeps any flaws found in it, because nobody fixes them.

### You can see how it makes money
Funding · Business model
Find out how the tool is paid for. If you pay nothing and see no ads, the money comes from somewhere else, such as donations, investors or data about its users, and it is worth finding out which.

### It works on your devices
Cross-platform
Check that it works on every device you would use it on. A password manager that works only on your computer will not help you sign in on your phone.

### You can actually use it
Usability · Documentation
Check that you can set it up and use it with its own instructions. A complicated tool that you set up wrongly or stop using protects you less than a simpler one you use every day.

## Notes
- No single row decides it on its own, so weigh them together.
- To see recommended tools in each category, use the guides that Spectra's steps point to. The people who write them keep their lists up to date.
